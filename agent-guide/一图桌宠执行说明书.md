# 一图桌宠 Agent 执行说明书

## 0. 接收输入并确认边界

Agent 记录原图路径、目标显示尺寸、是否需要打包 EXE，以及图片是否允许被修改和公开。原图不得被覆盖；真实照片默认只用于本地处理。

## 1. 环境检查与配置

```powershell
.\scripts\check_environment.ps1
.\scripts\setup_environment.ps1
```

Agent 可以自动检查 Windows、Python 3.12、Git 和项目写入权限，也可以创建 `.venv`、安装项目依赖。安装系统软件、修改环境变量或申请管理员权限前必须向用户说明并取得确认。

## 2. 登记原图和自拍成片

```powershell
.\scripts\start_onepic.ps1 -SourceImage "原图路径"
```

该命令完成三件事：

1. 在 `user_assets/source/` 保存原始文件副本；
2. 按原图完整像素内容生成 `user_assets/selfie.png`；
3. 创建 `user_assets/workflow.json`，将角色与走路状态重置为未确认。

自拍成片必须来自这张原图。不得使用标准角色图、动画末帧或项目演示照片替代。

## 3. 分析人物特色

生成之前先记录人物辨识特征，包括：

- 脸型、眼型、眉形、鼻唇比例和笑容；
- 发型、刘海、辫子、发色；
- 服装轮廓、颜色、配饰和随身物品；
- 人物整体气质；
- 原图未展示的全身部分必须标注为合理补全，不能冒充原图事实。

统一的是画面质量和后续动作规范，不是强制画风，更不能把所有人物套成相同模板脸。

## 4. 选择风格并只生成首张标准角色候选

这一阶段禁止生成整套动作。首张候选应为全身、透明或易去背、正面自然站姿，并尽量保留第三阶段记录的辨识特征。

生成后登记：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py character-candidate `
  --image "候选图路径" `
  --feature "特征一" `
  --feature "特征二"
```

Agent必须把候选图展示给用户，询问脸型、眼型、发型、服装和整体气质是否像。用户未明确确认时必须暂停，不能推测用户默认同意。

用户明确确认后执行：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py approve-character
```

## 5. 生成动作素材

只有 `check-actions` 通过后才能继续：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py check-actions
```

至少生成站立、坐下、入睡、拖拽、自拍和八相位走路。所有动作必须沿用已确认标准角色的脸型、发型、服装、配色、画风和身体比例。

惊讶应采用眼睛稍微睁大、嘴巴微张、一只手轻放胸前的克制姿势；不要生成双手高举、嘴巴大张的尖叫模板。情绪强度由程序的独立符号层补充，不要把符号永久画死在动作素材里。

八相位走路必须依次包含右脚落地、下压、左脚迈过、身体抬升、左脚落地、下压、右脚迈过、身体抬升。长发、辫子和裙摆需要与身体运动存在轻微滞后。

## 6. 自动素材检查

检查 RGBA、画布尺寸、透明通道、文件数量和 manifest 引用。逐帧排查多头、多手、多腿、脚底漂移、身体裁切、角色比例变化、跨格重影和背景残留。

`prepare_user_pet.py` 在角色未确认时会拒绝运行。发现错误时只重新生成问题帧，不覆盖已经验收的角色标准图。

## 7. 强制走路预览

动作生成后执行：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py walk-review
```

工具会生成：

```text
user_assets/review/walk-preview.gif
```

Agent必须向用户展示 GIF。用户重点检查左右脚是否交替、落脚是否稳定、身体是否下压和抬升、辫子或衣摆是否自然，以及循环播放是否像贴纸平移。

用户明确确认后执行：

```powershell
.\.venv\Scripts\python.exe .\tools\onepic_workflow.py approve-walk --yes
```

未确认时，程序不会加载私有角色，个人版本打包也会停止。

## 8. 运行与优化

```powershell
.\scripts\test.ps1
.\scripts\run.ps1
```

运行时移动采用 16 ms 时间驱动和亚像素累计；落脚阶段减速但不完全冻结，随后平滑加速，避免停顿后突然冲出。自动测试通过只代表结构正确，动作自然度仍以 GIF 和桌面实机验收为准。

## 9. 最终用户验收

检查角色相似度、跑动、坐下、睡眠、拖拽、自拍照片距离、多显示器清晰度和尺寸。用户指出具体问题后，只修复对应动作、帧或参数。

## 10. 打包

公开演示版默认不包含任何用户素材：

```powershell
.\scripts\build.ps1
```

角色和走路均确认后，用户可以构建自己的个人版本：

```powershell
.\scripts\build.ps1 -IncludeUserAssets
```

## 11. GitHub 发布

公开发布只上传代码、文档和明确授权的演示素材。检查 `.gitignore` 和公开构建目录，确保没有 `user_assets/`、真实照片、本机路径或私人流程状态。
