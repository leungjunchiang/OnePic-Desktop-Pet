# Agent 执行入口

本项目的目标不是让 Agent 只返回一段提示词，而是让 Agent 按固定架构完成环境检查、素材处理、代码配置、测试、视觉验收和打包。

执行时必须遵守以下顺序：

1. 阅读根目录 `AGENTS.md`、`文件夹说明.md` 和本文件；
2. 接收一张用户拥有使用权的角色图片，并用 `start_onepic.ps1` 登记；原图自动成为自拍成片；
3. 先运行 `scripts/check_environment.ps1`；
4. 缺少系统软件时停止并请求用户确认，不自动修改系统；
5. 运行 `scripts/setup_environment.ps1` 创建项目虚拟环境；
6. 让用户选择保留原画风、轻度 Q 版或完整 Q 版，分析脸型、眼型、眉形、发型、服装、配饰和气质，只生成首张标准角色候选；
7. 运行 `approve-character` 打开图形确认窗口；用户未亲自点击确认时必须暂停，禁止生成动作；
8. 标准角色确认后生成动作，并为八相位走路生成 GIF 预览；惊讶动作应克制自然，由独立“！”符号增强，不使用双手高举和大张嘴的尖叫姿势；
9. 用户未确认走路自然度时必须暂停，禁止加载或打包私有角色；
10. 两个门禁通过后运行素材检查、单元测试和启动冒烟测试；
11. 用户最终验收后才能运行个人版本打包；
12. 公开发布前再次执行隐私与授权检查。
