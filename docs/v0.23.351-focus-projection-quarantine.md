# v0.23.351：跨设备异常汇总隔离

服务器有效今日／本周总数包含实时设备投影，既有设计把它作为多处界面的下限。如果同设备同场次的迟到停止桥接已根据封存记录截短，这个聚合仍可能包含未经校正的桥接，从而覆盖正确的区间计算。

本版检测到上述明确冲突时，在本地账号状态写入一个按北京时间日期限定的隔离标记，暂停把有效汇总作为界面下限。标记跨重启有效，但不同账号和新一天不继承。收到有效的记录及实时投影后，独立的今日区间并集与服务器今日值相差不超过两分钟时，自动移除标记并恢复汇总。工作事实、历史记录、上传队列和服务端数据不被更改。

存在真实离线记录尚未抵达本机时，隔离期间其他设备的显示可能暂时偏低，补传一致后恢复。没有异常桥接证据时仍沿用既有服务器汇总兼容逻辑；因此不能保证所有无法观测的同步或设备故障都被识别。

回归覆盖重复读取异常总数、已显示高值的气泡纠正、重启持久性、账号／日期隔离、异常和正常汇总、离线记录恢复，并保留跨午夜和休眠测试。Mac 构建与自动回归不等于真实多机长期同步验收。
