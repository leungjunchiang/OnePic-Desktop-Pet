## 目标电脑尚需验收

1. 安装并登录 QQ 音乐，设置正确的 QQMusic.exe 路径。
2. 点击“随机听陈楚生（QQ 在线）”，确认客户端接受歌曲投递、实际有声音，并收到匹配的播放反馈。
3. 在聊天中测试换一首、精确点歌、暂停、继续和查看状态；重复点击应显示忙碌提示。
4. 检查未登录、需要会员、冷启动或弹窗拦截时显示“尚未确认”或具体错误，六毛不伪装成已确认陪听；不要据元数据反馈推断完整播放权限。

未构建或发布新的 EXE；本交付是可直接用独立环境运行和继续修改的源码开发版。`/playbysongid` 与目录端点是 QQ 客户端兼容性适配，尚未在这台机器验证真实音频或全部客户端版本。
