# 今日累计工作时长常驻

## 实际根因

v0.23.323 的 PetWindow._update_work_duration_bubble 和 WorkDurationBubble.set_session 两层都限定 focus/rest 才显示。结束本轮进入 idle 后，今天的账号累计仍然存在，UI 却隐藏整个胶囊。用户提供的 PR #24 修复说明尚不等于当前发布代码已包含这项修改，本次直接检查并修正发布分支。

PetWindow._refresh_desktop_coaching 无论计时框是否可见都使用其 x/y 定位训导牌；_update_work_duration_bubble 还会在累计框不显示时隐藏全部训导层。持续训导状态和用户的时长显示偏好因此耦合。

## 显示与定位

- 设置开启且宠物可见：focus 显示今日累计；rest 显示同一累计并标注已暂停；idle 保留累计，去掉已暂停，不表示本轮仍在计时。
- 零累计仍显示今日已工作 00:00。累计来源仍是原账号北京时间自然日显示投影，没有改账本、历史缓存、秒数或跨日校准逻辑。
- WorkDurationBubble 只更新内容，显示仍由 PetWindow 的非激活入口管理，继续遵守真正全屏、手动隐藏、关闭和被动 quiet mode；没有新增 focus/raise/activate 调用。
- 隐藏过的暂停胶囊重新在 idle 显示时清除旧暂停颜色与属性。
- 训导牌独立使用自己的显示门禁：可见计时框左侧对齐；用户关闭时长显示时居中锚定宠物下方，并按屏幕边界约束。全屏或手动隐藏仍隐藏双方。
- 右键和托盘共用菜单现在写作“显示今日工作时长”，开启/关闭反馈也使用今日口径。

## 验证与数据边界

tests/test_daily_duration_surface.py 覆盖真实开始→休息→结束、idle 累计和文案、隐藏的暂停样式恢复、零累计、全屏/手动隐藏及恢复、关闭计时偏好后训导牌备用定位并重新对齐。test_window 的特效避让回归改为结束本轮仍避让，真正关闭显示才清除胶囊避让区。

无新增网络 worker、查询、RPC、heartbeat 或 Supabase migration。不使用重置卡，不删除用户配置或专注记录。公开发布继续经过 Windows、macOS Apple Silicon 和 Intel 的现有测试与打包门禁。
