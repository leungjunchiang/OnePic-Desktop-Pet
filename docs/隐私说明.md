# 隐私说明

本说明用于保护未授权或不希望公开的图片。虚拟角色本身不等同于真人隐私；如果仓库所有者拥有角色与图片的公开使用权，可以在补充素材授权后将其作为公开演示素材。

## 默认边界

- 程序默认使用纯离线对话，不上传角色图片、自拍或工作计时数据；
- 用户主动选择 Codex、DeepSeek、Kimi 或其他兼容 API 后，当前消息与最近少量文字上下文会发送给对应服务；
- Codex 联动使用临时、只读会话；不向 Codex 发送角色图片、自拍、项目文件或工作计时数据；
- API 令牌由操作系统安全凭据库保存，不进入 `settings.json`、源码、构建产物配置或 GitHub；
- 聊天历史只存在于当前进程内存，关闭应用后不会保存；自动牢骚和报时始终使用本地规则；
- 用户照片只从本地 `user_assets/` 读取；登记原图时会保留私有原始副本并生成同分辨率 `selfie.png`；
- `user_assets/` 图片默认被 Git 忽略；
- 程序只在当前用户本地应用数据目录保存窗口位置和显示尺寸。
- 程序还会在同一目录保存 AI 提供方、API 地址、模型名称、牢骚与报时开关；这些设置不含令牌。

## 公开前检查

1. 检查 `git status --ignored`，确认私人图片处于忽略状态；
2. 检查源码中不存在本机绝对路径、账号、密钥和个人信息；
3. 使用不带 `-IncludeUserAssets` 的默认命令重新构建公开 Release；
4. 检查 `dist/Lili/`，确认不包含私人照片、令牌或本机设置；
5. 如果私人图片曾经进入 Git 提交，不要只删除当前文件，应在公开前重建干净历史。
