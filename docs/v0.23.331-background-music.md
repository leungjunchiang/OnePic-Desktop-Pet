# v0.23.331 后台音乐与轻量歌单

随机入口默认在后台生成 30 首并播放，不再打开歌单窗口。需要查看时，在六毛菜单或
快捷口袋点击“查看陈楚生歌单”。窗口独立于置顶桌宠，可最小化、关闭或重新打开；
这些操作不暂停音乐。上一首、下一首、双击选曲和重新随机继续复用同一个串行控制器。

窗口默认 350 × 410，移除顶部说明与底部整段反馈、重复歌手名和横向滚动条。
完整歌名及合作歌手保存在悬停提示，状态只显示播放或暂停。自动续播不反复弹出
窗口或长消息，错误和未确认结果继续反馈；后台投递只最小化完整路径匹配的 QQ 窗口。

## macOS 试验适配

在干净 macOS runner 只读检查了官方 QQ Music 11.10.5 包，包标识为
`com.tencent.QQMusicMac`，只注册 `qqmusicmac` URL scheme，没有播放脚本字典。
检查不安装、不运行 QQ，不读取用户数据或音频。工具为 `tools/inspect_qqmusic_macos.py`。

因此 Mac 接入公开 ApplicationServices Accessibility 接口，需要用户先启动、登录
QQ，并在“系统设置 → 隐私与安全性 → 辅助功能”允许 Lili。适配只查找唯一 QQ 进程，
使用其搜索框、匹配完整歌名与歌手的歌曲行，以及明确播放栏；不激活前台窗口、
不发送全局按键、不使用未经验证的播放 URI，也不读取账号凭据。

仅当播放栏公开明确状态、歌名、歌手和时间轴时确认播放并续播。Mac 播放栏不一定
公开专辑；缺少专辑时仅对明确标记的 Mac AX 快照放宽专辑比较，Windows 仍严格比对。
权限不足、控件版本不兼容或状态不明确时返回具体失败，不把启动或 AXPress 当作成功。

Mac QQ 控制是试验适配：单元和两种 Mac 架构构建可以验证 API、界面及打包，
CI 没有用户登录的 QQ 和辅助功能授权，不能代替 Mac 真机的在线播放验收。
DMG 沿用现有临时签名方式，未使用 Apple Developer ID 签名或公证。

## 验证与发布

Windows、Apple Silicon、Intel 独立回归和构建；冻结程序需通过隔离启动、退出，
Mac 另验证应用临时签名与 DMG 完整性。仅把通过验证的相同提交打包上传。
公开安装包和源码排除用户数据、私人素材、开发环境与实机日志，不触发云数据库部署。
