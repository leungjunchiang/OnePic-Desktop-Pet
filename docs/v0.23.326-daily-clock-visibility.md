# v0.23.326 · 今日已工作只跟随六毛显示

## 根因

v0.23.324 已去掉 focus/rest 限制，但 `_update_work_duration_bubble()` 最后仍调用默认 `source="passive"` 的 `_show_nonactivating()`。该入口的 `_surface_block_reason()` 会检查消息 quiet mode。因此进程级游戏、OBS、会议识别可以在六毛仍可见时拒绝显示今日计时。置顶切换、全屏恢复也经过相同入口，会再次误用消息门禁。

截图不能证明当时具体哪个进程被识别；本次修复针对实际存在的显示路径，回归直接模拟 quiet mode。

## 显示规则

- 开启“显示今日工作时长”且六毛可见：idle / focus / rest 和零累计都显示。
- 消息免打扰不隐藏今日计时，也不影响六毛退出全屏后恢复。
- 关闭该设置、六毛隐藏或应用退出：计时框隐藏。
- 真正全屏仍由原有进程级显示管理器隐藏六毛和附属计时框；退出全屏恢复两者。
- 共有显示入口按窗口身份识别 `pet_status`，确保置顶旗标重建和恢复路径一致。其他消息保持原来的被动门禁。
- 保留 WA_ShowWithoutActivating、NoFocus 和原有 Windows/macOS 原生非激活策略；不新增网络、定时器或专注统计字段。

## 验证

新增回归覆盖 quiet mode 下的 idle/focus/rest、零累计、关闭并重新开启设置、手动隐藏/恢复、直接 hide/show、置顶切换，以及全屏退出后仍处于 quiet mode 的恢复。普通互动仍被 quiet mode 拦截。

复用既有计时胶囊、状态解析、全屏管理器和原生窗口策略；不修改累计时间、账号、历史数据或数据库。升级无需重置卡。
