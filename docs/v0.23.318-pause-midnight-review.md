# v0.23.318：PR #24 核对与补充修复

## 核对结论

PR #24（fix/v0.23.316-focus-time-consistency）实际基于 release/v0.23.315；Windows 测试 run 37034889870 失败，不能直接当作已通过的新版本合并。失败用例通过 DisciplineDialog.__getattr__ 读取 workspace 缓存，但对 dialog 赋值清缓存，没有清掉真正持有缓存的 QWidget；构造过程已经读过历史，下一次没有再读，calls 为 0 而断言要求 1。新回归操作 dialog.workspace 并固定北京日期及单调时间，不依赖执行当天。

v0.23.317 已解决 checkpoint 丢亚秒、共享缓存锚点归零、榜单/卡片不同投影及跨周缓存；本轮复用这些更严格的 canonical 来源、用户 ID 与北京周过滤，不引入 PR 中另一个重复 reconcile 函数。

## 不采用的绝对规则

不将任何更高显示永久写回账本，不规定同日权威事实绝对不能下调。睡眠、十分钟未操作的延迟检测、重叠区间去重或经校验事实修订都可能合法减少时长。界面临时防回退不能掩盖这些修正。下调许可只存在本地显示，不使用重置卡，不删除历史，不以用户估计值补写 FocusSession。

已有 10/02 的专注留在 10/02 与本周总量，不能搬到 10/03 来避免午夜重置。分钟文本仍向下取整。
