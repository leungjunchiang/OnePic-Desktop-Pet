# v0.23.342 · 每轮现场版最多六首

每次随机生成三十首，整轮 Live／现场录音最多六首。热门前五十对应曲名抽十五首，
完整曲库排除已选后再抽十五首，最后一起打乱；曲名和 ID 不重复，跨轮允许重复。
完整曲库部分也可能选到其他热门歌，因此最终热门数可以超过十五。

现场判定使用曲名、专辑、原始曲目副标题和专辑名称中的明确标记，包括 Live、
Livehouse、Concert、现场／現場、演唱会、音乐会和巡演，不靠音频推测。
普通英文 Alive、Delivered 不算 Live。同一基础曲名仍只保留一个版本，
同等订阅条件优先录音室版本；无需订阅的完整版本优先于需订阅条目。
未标记的现场录音可能无法从目录元数据识别，版权及账户权限仍由 QQ 判断。

两个抽样部分共用六首额度，手动重新随机和自动换轮使用同一规则。
若目录无法同时满足三十首、热门十五首和现场最多六首，则提示并保留原歌单，
不静默放宽上限。自动换轮继续复用候选池，不在曲终联网；现有登录、客户端启动、
原生顺序队列和窗口规则不变，Windows、Mac 共用本次抽样实现。

已保存的旧歌单仍可查看，重启不自动播放。升级后点击“随机听陈楚生”即可按
新规则重新生成，无需清空设置或重新登录。随包热歌快照降级同样遵守上限。

验证：新增现场识别、零至六首热门现场的共享额度、恰好二十四首非现场边界、
目录不足保留磁盘与内存歌单、同名版本优选、旧歌单兼容及缓存换轮回归。
