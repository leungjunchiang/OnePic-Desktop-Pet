# v0.23.340 · 每轮随机三十首，允许跨轮重复

每次点击“随机听陈楚生”重新抽三十首，轮内按基础歌名合并不同版本并去重。
不同轮次允许重合，首曲也可以与之前首曲或 QQ 当前歌曲相同；不要求新一轮
全部换成没有听过的歌曲。播完本轮后继续从候选池随机下一轮，可随时暂停。

删除最近十次首曲避让和为抽样额外读取当前媒体信息的步骤，不再维护首曲历史。
旧版保存的 recent_starts 字段忽略，原有三十首、位置与轮次可继续加载；仅加载
列表不会自动出声。再次随机保存新列表时按新格式保存。

仍使用系统随机，每次重新洗牌和抽取；可以偶然抽中之前的相同歌曲或相同顺序。
优先无需订阅的版本，实际版权和播放权限由 QQ 决定，并非所有版本等概率抽样。
仍过滤伴奏、明确试听片段和不足九十秒条目。Windows 普通曲终继续交给 QQ
原生队列衔接，自动换轮复用缓存候选池，不在曲终请求目录。
