# v0.23.353：续传与备用下载

六毛检查更新时优先使用官方 GitHub API；API 无法访问时尝试官方 Release 页面。安装包摘要来自官方 API 的 `digest`，或官方同版本 `.sha256` 文件；没有可信摘要时拒绝下载和安装。第三方线路只承载本仓库精确的 Release 安装包，不能提供版本信息或校验值，确认窗口说明第三方可见下载请求与 IP。

每个临时断点用官方 URL、文件大小和 SHA-256 绑定身份。继续请求 `Range` 时验证 206 的起点、终点和总长度；服务器返回 200 则安全从头覆盖，416 则清理本次不匹配的临时断点后重下。文件短缺、超长或摘要不匹配不能安装；中断时保留可续传数据，成功后原子替换完成文件。

官方线路连接失败、读取中断或持续低速时尝试第三方 ghfast.top，备用失败后再试官方线路。第三方可用性和下载速度不受项目控制；如果官方版本信息与校验值都不可达，无法验证的安装包不会被使用。由于 v0.23.352 及以前的更新器没有本功能，首次更新到本版仍使用旧下载器或手动下载。

本机对已发布的公开 Windows 安装包完成真实网络测试：官方连接在收到 64 KiB 后人为断开，备用线路从该位置续传完成，最终长度及官方 SHA-256 一致；未安装或运行安装包。此结果不等于其他地区或将来都能达到相同速度。自动化覆盖失败与低速切换、206/200/416、短响应、错误范围、旧摘要、第三方篡改、确认提示和官方元数据回退。Mac 包通过自动构建及测试，尚未在真实 Mac 上做网络续传验收。
