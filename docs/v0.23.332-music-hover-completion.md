# v0.23.332 音乐悬停快捷键与曲终判定

双击六毛打开快捷口袋后，在音乐按钮停留 120ms，正上方显示“随机听陈楚生”。
它与工作报告共用同一二级状态切换、显示/隐藏计时器和非激活窗口。按钮为同尺寸
蓝红黄随机图标，移到上方可以点击，离开主按钮和二级按钮后 160ms 收起。移到其他
主按钮会切换或隐藏，快捷口袋整体隐藏时一并收起。仅悬停不点歌，点击才创建新一轮
30 首并在后台播放。音乐主按钮仍可打开原有播放、暂停、切歌及查看歌单菜单。

修复原有 60ms 鼠标轮询每次重启 160ms 隐藏计时器的问题；定时隐藏不会因持续轮询
一直延后。工作报告与音乐共用修复，Windows 预留的透明第二行不改变主行位置。

原曲终判断只要观测到最后 2.5 秒，再看到停止状态或歌曲元数据变化就立即切歌，
可能在旧曲剩余尾音时抢切。系统外推进度也可能让旧快照提前进入曲末范围。
本版保留外推进度供显示，续播改用客户端原始位置：仅从可信曲末记录建立完整时长
截止时间，且结束状态/下一曲元数据需连续稳定至少 1.2 秒。完整时长之前不发下一首；
一直 Playing 不触发、未知时长不触发、回拉进度清除旧证据，暂停继续优先取消续播。
Windows 读取原始 GSMTC 位置；Mac 使用既有 AX 真实时间标签，共用严格结束判断。
QQ 自身的试听、音效或交叉淡化仍由 QQ 决定，本修复限定六毛发出的切歌命令。

回归覆盖原始进度与外推不一致、剩余尾音中的短暂元数据变化、缓冲/停止、稳定自然
换曲、回拉进度、暂停竞态和 30 首后换轮；悬停测试对工作报告与音乐使用相同用例。
Mac QQ 点歌仍为试验适配，无登录客户端的 Mac 真机播放验收；两架构执行回归、
冻结应用正常 Cocoa 启动退出、临时签名及 DMG 完整性检查。DMG 未经 Developer ID
签名/公证。无用户数据迁移或云服务部署，不将本机测试日志打入公开安装包。
