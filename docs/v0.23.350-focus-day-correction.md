# v0.23.350：今日计时修正

跨设备实时投影可能暂时高估当天工作时长，随后有效同步虽已纠正，显示平滑层仍可能保留旧高值。本版允许同账号同一天的有效实时快照在修正超过一分钟时更新显示；无效快照和仅本地刷新不能触发这一回落。

仅对临时的停止桥接区间，如果同设备同场次已有封存事实，且桥接终点比最后事实晚超过一个十五分钟检查点和两分钟新鲜期，则用事实终点限制临时显示。正在工作的实时区间不受影响。离线工作尚未补传时，其他设备的临时值可能暂时偏低；事实抵达后自然恢复。本地和服务器的封存记录、上传队列与历史不被修改。

服务器实时快照带有新鲜期信息时，以设备最后活跃时间或停止时间过滤已过期的缓存；旧协议保持兼容。独立心跳线程重发输入证明时计算实际经过时间，防止休眠后把旧操作当成新操作；在线状态与工作状态仍分别处理。

回归覆盖跨午夜、桌宠气泡高值纠正、失效数据、停用桥接、正常活跃及离线补传、休眠后输入证明和北京时间边界。Mac 客户端构建和自动测试不能替代实际设备上的长期同步验收。
