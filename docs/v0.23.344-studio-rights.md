# v0.23.344 · 随机排除现场及无授权条目，会员曲保留

每轮仍是热门前五十对应曲名随机十五首、完整候选池排除已选后随机十五首，
合并打乱、三十首不重复，跨轮可以重复。会员或付费歌曲保留，与其他合格歌曲
同等洗牌，不再优先免费歌曲。会员限制与无版权是不同状态。

随机在同名版本归并之前排除 Live、现场、演唱会、音乐会、巡演、晚会、义演、
首唱和节目分期录音；结合曲名、专辑及副标题判断，兼容全半角及大小写。
元数据缺少专辑或无法确认播放授权的条目也不用于随机。没有标记的实际现场
录音无法仅靠元数据绝对识别，本规则不分析音频。

版权判定依据 [QQ 官方前端](https://y.qq.com/ryqq/js/common.chunk.ad5e47b12e2ca2168529.js?max_age=2592000)
的歌曲归一化规则：完整播放权限对应 switch 位 1、2、3、17；pay_play/payplay
或 pay_down/paydownload 表示另行付费授权。没有完整播放或付费授权的条目不
加入随机，只有试听权限也不算完整授权；未知不按可用处理。会员标记不会
因为免费播放位为零而被误删。原生队列发送前也校验授权资料。

这些公开目录字段不证明当前账号、地区或某一时刻的实际权益。播放仍交给 QQ，
不读取登录凭据、不获取媒体地址、不改变会员设置、不绕过授权；不承诺没有
会员时试听结束会自动跳过。目录暂不可用时沿用明确标注的随包快照，并新增
六十首有完整元数据的非现场授权曲备用表；快照有核对日期，不代表永久版权。

自动换轮复用本次合格候选池，不在曲终联网。旧歌单仍可查看，重启不自动播放；
如果含现场或缺少授权确认，禁止直接投递并提示重新随机，不自动删除历史。
升级后点“随机听陈楚生”生成新规则歌单。

验证覆盖每个完整播放位、会员及付费授权、明确无授权、缺失／畸形字段、
同名现场不能覆盖会员录音室版本、两池与缓存换轮过滤、旧歌单恢复与投递门禁，
以及六十首备用资料的原生协议校验。QQ 官方公开目录已进行一千轮元数据
抽样，各三十首无曲名／ID 重复、至少十五首热门、现场为零且全部有授权标记。
抽样验证模拟播放确认，不代表一千轮音频均已播放。

Windows 生产管理器随机《隔壁阿丑》，按列表下一首依次《一夜》《庙堂之外》，
三首均确认起播及正确顺序；这不是三首自然播完的验收。三十首含十五首热门、
二十四首会员曲、零现场。QQ 对《一夜》给出约三百二十二秒，与目录相符；
对其余两首返回约六十秒，故不记为会员整曲权益验收，也不据此判定用户没有会员。
之前《这样的生活》的完整时长检查也按未通过处理；运行时权益仍由 QQ 负责。
一项资料不完整条目的额外选曲未确认匹配，之后新增缺少专辑不入池限制。

另一次 QQ 超过十秒才起播，旧确认窗口已提前报失败。默认等待改为二十五秒，
只投递一次、不因未确认重启 QQ，用户取消仍优先；有十二秒后起播和取消回归。
测试采用独立三十秒守卫，最终还观察延迟起播并结合媒体状态和音量计确认停播。

针对用户报告偶发账号掉线，代码审计未发现音乐链路退出登录、切换账号或修改
凭据的动作；已有 Windows 客户端继续复用唯一运行版本，冷启动不携带音乐参数。
实际账号掉线没有复现，不能宣称已找到或消除了根因。界面检测就绪不等于账号
会话健康，暂未读到控件也不代表账号已退出。

Mac 现在区分普通静态登录文字与真实登录按钮／窗口、登录中及验证；客户端
若提供 AXHidden 则过滤隐藏子控件，后台窗口仍保留只读识别。瞬时登录提示连续
两次确认，未就绪不搜索、不点击、不操作认证界面；设置自检新增只含阶段的就绪
观察。模拟 AX 树、隐藏分支、真实登录拦截、瞬时恢复和后台窗口回归通过。

Mac QQ 在线仍为试验适配，没有本次已登录、已授权 Mac 真机在线验收；双架构
