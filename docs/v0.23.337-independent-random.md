# v0.23.337 · 随机曲库与 Mac 客户端选择

此前随机由 SystemRandom 提供，并未固定《山高水长》，但目录主要来自搜索首批
结果和备用元数据，Windows 自动换轮只重排原三十首。之前的自然曲终验收脚本
曾为五分钟时限主动选择《山高水长》，该测试脚本不属于安装包，也不决定随机入口的首曲。

随机入口现优先分页读取陈楚生公开歌手目录，按完整版本标题核对歌手、类型、
数字 ID 和原生队列所需元数据；缓存十分钟，排除伴奏、Instrumental、Karaoke。
同名不同版本合并时优先无需订阅的录音。系统随机从有效候选中抽取三十首，列表内
不重复；优先无需订阅的曲目，实际地区、版权、登录和会员权限仍由 QQ 判断。
它不是对所有版本、所有权限歌曲的无条件等概率抽样。

首曲还会避让当前 QQ 正在播放的歌和最近十次已确认首曲；最近记录只保存在本机，
重启继续生效。不同电脑各用系统熵及本机状态，不要求生成相同歌单，也不承诺两台
电脑随机结果永不偶合。目录失败使用随包公开元数据，仍由 QQ 在线播放音频。

Windows 首次播放前预备整个候选池的完整资料。自动换轮从缓存候选池重新抽取
三十首，而不局限在原三十首；普通曲终继续交给 QQ 原生队列，换轮不联网查询。
重启后仅恢复列表，不自动出声；用户继续时重新交给 QQ。
模式读回优先在已核对进程的 QQ 窗口中使用 UIA 原生缓存条件查询，避免逐节点
读取深层网页耗尽模式辅助进程的时间；不可用时仍保留有限遍历和失败暂停。

Mac 设置选择器改用可选择 .app 包的原生文件面板。校验 QQ 包标识及包内可执行
文件；选择包内程序会归到 .app 根目录，选到目录、其他播放器或损坏包不覆盖原值。
LaunchServices 可补充查找改名或非默认目录的 QQ；别台电脑保存的 Windows 地址
不在 Mac 执行。首次仍需用户安装、打开并登录 QQ，并授予 Lili 辅助功能权限。
这些是软件自身的设置和运行流程，不依赖 Codex、项目 venv 或测试脚本。

Mac QQ 在线控制仍是 AX 实验适配，需要真机带登录和授权验收。两种架构完整回归、
DMG 构建和冻结启动不能证明 QQ 实际搜索、播放和连续换轮已成功；没有该证据时
不能宣称 Mac 音乐已全面兼容。DMG 仍未 Developer ID 签名或公证。
