# 六毛歌曲作品理解层

`chen_chusheng_song_cards.json` 只保存歌名、作品标签、情绪、意象和六毛的使用建议，不保存歌词正文，也不提供逐句歌词索引。

运行时，六毛会优先读取用户在设置中选择的歌词 TXT；如果没有设置，会尝试读取当前用户桌面的 `陈楚生歌词.txt`。原文只在本机内存中短暂解析，用于判断用户输入的较长片段属于哪首歌，随后只把歌曲名称和作品卡交给 AI。歌词原句不会进入模型提示词、聊天回复、构建产物或 GitHub Release。

这是有意的隐私和版权边界：Release 用户可以获得歌曲的作品理解能力，但不会从公开包中导出完整歌词或逐句歌词数据库。
